Will Metro Manila Adults Act on the Alert?

Prototype of the system for our study on whether message completeness and language change how well adults understand a phone emergency alert and whether they intend to act on it.

Five elements: hazard, location, time, guidance, and source. Each version is written for flood, extreme heat, earthquake, and air quality alerts.

Respondent flow

  1. Consent and screening (18 or older, Metro Manila)
  2. Six-item profile, then random assignment to one version
  3. Four alerts in random order, each on a lock screen for up to 30 seconds
  4. After each alert: intention-to-act scale, then the comprehension test
  5. Preference pick for each alert type, then debriefing

Behind the scenes

Settings

In the real study, a browser that already submitted cannot answer again. Use the button above to clear that marker for testing.

Alerts

All 16 simulated alerts. Each complete alert is the typical alert with the time and the guidance added; the sender is the same.

Real alerts the typical versions are modeled on

Table 1 of the paper: four NDRRMC rainfall alerts sent to Metro Manila in 2025 and 2026, checked with the same element checker.

Composer

For alert writers. Fill in the five elements and the composer writes a complete alert in Filipino and English.

Draft

The system never sends alerts. Approved text is copied by the writer into the official channel.

Checker

Paste any alert to see which of the five elements it has. The send time in parentheses does not count as the time element.

Evaluate

System evaluation questionnaire based on ISO/IEC 25010. Answered by IT experts and DRRM staff after using the simulator and the composer.

1 = Strongly Disagree, 2 = Disagree, 3 = Neutral, 4 = Agree, 5 = Strongly Agree
